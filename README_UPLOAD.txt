GITHUB-UPDATE
1. ZIP entpacken.
2. Repository SHK_Lernapp öffnen.
3. Add file -> Upload files.
4. ALLE DATEIEN AUS DEM ENTPACKTEN ORDNER hochladen.
5. NICHT den Ordner selbst und NICHT die ZIP hochladen.
6. Vorhandene index.html, app.js, questions.js, sw.js, manifest.webmanifest und Icons ersetzen.
7. Alle Bilddateien ebenfalls hochladen.
8. Commit changes.
9. 1-3 Minuten auf GitHub Pages warten.
10. App auf iPhone/PC öffnen.
11. Falls noch der alte Stand erscheint: „↻ App aktualisieren“ drücken.

ALTE LOKALE IMPORTS
Wenn ein früher lokal importiertes Paket jetzt fest eingebaut ist, wird es automatisch entdoppelt.
Die Statistik wird nicht gelöscht.

ZUKUNFT
Neue Fragen können weiterhin als JSON importiert werden.
Sollen neue Inhalte automatisch auf ALLEN Geräten erscheinen, werden sie bei einem späteren
zentralen App-Update wieder in questions.js eingebaut.
